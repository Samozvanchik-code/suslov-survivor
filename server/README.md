# Сервер мирового рейтинга

Маленький Cloudflare Worker: принимает результаты забегов, хранит топ-100
и возвращает место игрока в мире. Бесплатного тарифа хватает с запасом —
100 000 запросов в день, а один забег это один запрос.

Игра работает и БЕЗ него: пока `АДРЕС_РЕЙТИНГА` в `config.js` пустой,
топ остаётся локальным, на устройстве. Сервер только добавляет мировой.

---

## Как это уживается с GitHub Pages

Это ДВЕ РАЗНЫЕ площадки, они не конфликтуют:

- **Игра** как лежала на GitHub Pages, так и лежит. Ничего не меняется.
- **Сервер рейтинга** живёт у Cloudflare, отдельным адресом.

GitHub Pages умеет отдавать только готовые файлы и не умеет ничего хранить
и считать — поэтому рейтинг там сделать невозможно в принципе, нужна вторая
площадка. Игра просто ходит на неё запросом.

Папку `server/` можно спокойно держать в том же репозитории: Pages её не
трогает, секретов в ней нет.

## Что нужно один раз

Аккаунт Cloudflare (бесплатный, регистрация по почте) и установленный Node.

Проверить, есть ли Node:

```
node -v
```

Ответ вида `v20.11.0` — всё есть. Ошибка «не является командой» — поставить
с nodejs.org, кнопка LTS, дальше «Далее-Далее», после установки закрыть
и открыть консоль заново.

## Развернуть

Команды выполняются в КОНСОЛИ НА СВОЁМ КОМПЬЮТЕРЕ (не на GitHub), находясь
в папке `server/`. На Windows: открыть папку `server` в проводнике, в адресной
строке проводника набрать `powershell` и нажать Enter — консоль откроется
сразу в нужной папке.

**1. Войти в Cloudflare**

```
npx wrangler login
```

Откроется браузер, подтверждаешь доступ.

**2. Создать хранилище**

```
npx wrangler kv namespace create RATING
```

В ответе будет строка вида `id = "3f2a...c91"`. Скопируй этот id
и вставь его в `wrangler.toml` вместо `СЮДА_ID_ИЗ_КОМАНДЫ_СОЗДАНИЯ`.

**3. Выкатить**

```
npx wrangler deploy --config wrangler.toml
```

**Флаг `--config` обязателен.** Без него wrangler может подцепить чужой
конфиг из папки выше и выкатить не то — так уже было один раз: вместо
сервера залилась копия игры. Признак промаха в выводе: строка
`Read ... files from the assets directory`. Её быть не должно.

В конце напечатает адрес вида
`https://suslov-reyting.твой-аккаунт.workers.dev`.

Правильный вывод содержит имя `suslov-reyting` и строку про привязку
`env.RATING`, а строки про assets — нет.

**4. Проверить, что живой**

Открой в браузере адрес с `/health` на конце. Должно ответить
`{"живой":true,...}`.

**5. Включить в игре**

В `config.js` вписать этот адрес:

```js
const АДРЕС_РЕЙТИНГА = 'https://suslov-reyting.твой-аккаунт.workers.dev';
```

Без завершающей косой черты. Игра сама добавит `/score` и `/top`.

Залить игру на GitHub Pages заново — и мировой топ работает.

## Ручки

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/score` | принять результат, вернуть `{место, всего, вТопе}` |
| GET | `/top?n=10` | отдать топ (максимум 50) и общее число игроков |
| GET | `/health` | проверка живости |

## Проверить руками

```
curl https://твой-адрес/health
curl https://твой-адрес/top?n=5
```

## Что нужно знать про честность топа

**Личность — только ник, без регистрации.** Это осознанный выбор: игра
должна открываться и играться в один клик. Следствия:

- Два человека могут взять один ник. Держится одна лучшая запись на ник,
  так что «победит» лучший результат из двоих.
- **Результат отправляет браузер, значит его можно подделать.** Кто угодно
  откроет консоль и пошлёт «десять минут» руками. Полностью это лечится
  только просчётом всего забега на сервере — для такой игры оверкилл.

Что сделано вместо этого:

- проверки правдоподобия: время в пределах десяти минут, убитых не больше
  чем физически успевает заспавниться, уровень бьётся с числом убитых,
  спасённых не больше числа прошедших ивентов;
- ограничение частоты: 10 отправок в минуту с одного адреса;
- ники чистятся от тегов, управляющих и невидимых символов.

Это отсекает всех, кроме упорных. Упорных — руками:

```
npx wrangler kv key get --binding RATING "топ"     # посмотреть
npx wrangler kv key put --binding RATING "топ" '[...]'   # переписать
```

Если однажды понадобится настоящая защита — считать забег на сервере
или подписывать результат ключом, который живёт не в браузере.
